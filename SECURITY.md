# Security

Report a vulnerability **privately**: *Security → Report a vulnerability* in this repository (GitHub's
private vulnerability reporting), not in a public issue.

Only the maintainer changes this repository and publishes releases. A release is the signed `ccc.apk` with
`SHA256SUMS` and `SHA256SUMS.asc`; the certificate fingerprint and the GPG key are in the README. Do not
install an APK that does not match them.
